# Security policy

bodhi-mcp is a read-only client: it sends anonymous GET requests to Bodhi's
public API and stores no credentials.

To report a security issue, please use
[GitHub private vulnerability reporting](https://github.com/gunjansonaw/bodhi-mcp/security/advisories/new)
rather than a public issue.

Issues in Bodhi itself should go to the
[Bodhi project](https://github.com/fedora-infra/bodhi).
